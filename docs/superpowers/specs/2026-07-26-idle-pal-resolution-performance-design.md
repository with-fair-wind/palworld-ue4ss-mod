# PalworldEditor 常驻帕鲁解析性能修复设计

## 背景

当前 `game_thread_tick()` 在每个 EngineTick 都调用 `pal_game::resolve_selected_otomo()`。
该函数每次都会全局枚举 `PalOtomoHolderComponentBase`，再通过多次反射调用读取本地控制器、
当前高亮槽位、个体 Handle、Parameter、GUID 和 CharacterID。即使用户从未打开技能编辑、
没有锁定目标、也没有待处理技能请求，这条完整解析链仍按游戏帧率执行。

游戏线程随后还会在每帧获取技能快照互斥锁并重写大部分字段。两项常驻工作共同造成
PalworldEditor 仅加载时也可能降低帧率。

## 目标

- 未选择帕鲁且没有选择/技能编辑请求时，不执行任何当前帕鲁反射解析。
- 用户点击“选择当前帕鲁”时立即解析。
- 用户提交技能修改时立即重新解析并校验目标 GUID。
- 已锁定目标时每 250 毫秒校验一次当前高亮帕鲁，允许 GUI 最多延迟约 250 毫秒显示目标变化。
- 不跨帧缓存任何 `UObject*`、数组地址或 `FProperty*`。
- 技能快照只在其可观察内容发生变化或请求状态变化时发布。
- 保留现有世界代次、显式目标锁定和写前 GUID 校验安全约束。

## 非目标

- 本轮不修改据点资源发现、预览或实际扣料逻辑。
- 不改变启动时的一次物品扫描和技能目录加载。
- 不 Hook 数字键、队伍槽切换或详情页函数。
- 不降低技能修改时的目标一致性校验强度。

## 方案

### 解析调度器

新增不依赖 Unreal 的纯值调度器，校验间隔固定为 250 毫秒。每个 EngineTick 根据以下输入决定
是否需要调用 `resolve_selected_otomo()`：

1. 存在“选择当前帕鲁”请求：立即解析；
2. 技能编辑队列非空：立即解析；
3. 已锁定目标且距离上次后台校验达到 250 毫秒：解析；
4. 其他情况：不解析。

立即解析会同时刷新下一次后台校验时间，避免同一帧或紧邻帧重复解析。进入 LoadMap 前后重置
调度器，使旧世界时间点不影响新世界。

### 当帧对象生命周期

解析结果中的 `UObject* parameter` 只在执行解析的当前 EngineTick 内使用：

- 选择请求用它读取并确认目标状态；
- 技能编辑请求用它执行写前 GUID 校验和实际修改；
- 后台校验只提取纯值 GUID、名称和解析状态。

跨帧仅保留 `SelectedTargetObservation`、解析状态和诊断计数，不保留 Unreal 指针。没有当帧解析结果时，
不得执行技能写入；编辑请求本身保证触发立即解析。

### GUI 一致性

已锁定目标时，后台校验以 4Hz 更新 `targetMatchesCurrent`。用户按数字键切换高亮后，修改按钮最多继续显示
约 250 毫秒；但如果期间提交修改，该请求会触发立即解析，因此仍会在写入前拒绝错误目标。

未锁定目标时不进行后台解析。GUI 保留最近的纯值解析状态，直到用户发起选择或世界切换；这不会授权任何写入。

### 脏快照发布

游戏线程维护一份待发布的技能快照和 dirty 标志。以下事件标记 dirty：

- 选择请求开始或完成；
- 技能请求入队、执行、拒绝或清空；
- 后台校验得到不同的解析状态、观察 GUID 或目标匹配结果；
- 技能目录刷新完成；
- 世界切换；
- 其他现有可观察状态确实变化。

只有 dirty 时才获取 `skillSnapshotMutex_` 并更新共享快照。EngineTick 不再无条件复制字符串、
技能状态和目录状态。

GUI 线程继续只读取互斥锁保护的纯值快照。

## 错误处理

- 选择或编辑触发的立即解析失败时，沿用现有分阶段错误消息。
- 后台校验瞬时失败只更新解析状态并暂停写入，不自动清空显式目标。
- 世界切换继续清空所有待处理请求和写权限。
- 调度器只处理时间与状态，不执行反射，也不吞掉解析错误。

## 测试

纯 C++ 测试覆盖：

- 未选择目标、没有请求时连续 tick 不触发解析；
- 已锁定目标后，250 毫秒内不重复解析；
- 达到 250 毫秒时触发一次后台解析；
- 选择请求无视节流并立即解析；
- 技能编辑请求无视节流并立即解析；
- 立即解析后重新计算下一次后台校验时间；
- 世界切换重置调度状态；
- dirty 标志只在状态变化时消费一次。

构建验证：

```powershell
cmake --build --preset ninja-msvc-x64 --target format-check PalworldEditor PalworldEditorTests PalworldEditorBaseResourceSharingTests
ctest --test-dir build --output-on-failure
git diff --check
```

游戏内验证：

1. 关闭据点资源共享，仅加载 Mod，对比未加载 Mod 时的稳定帧率。
2. 未点击“选择当前帕鲁”时确认不再持续输出或执行帕鲁解析。
3. 选择目标后用数字键切换，确认约 250 毫秒内 GUI 显示目标不匹配。
4. 在切换后的 250 毫秒窗口内立即提交技能修改，确认写前即时解析会拒绝错误目标。
5. 退出世界并重进，确认旧请求失效且必须重新选择目标。
