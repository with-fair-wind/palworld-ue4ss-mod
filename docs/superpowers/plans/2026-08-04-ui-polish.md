# PalworldEditor UI 美化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `PalworldEditor` 的 ImGui 界面从“又高又窄的长条 + 默认灰样式”改为顶部 Tab 分页 + 深色现代主题，纯表现层改动。

**Architecture:** 新增 `src/mod/editor_ui.cpp`(+`inc/mod/editor_ui.hpp`)承载样式主题与 UI 编排；`render_main_window`/`render_diagnostics` 作为 `PalworldEditorMod` 的 static 成员（在 `mod_core.hpp` 声明、`editor_ui.cpp` 定义），以访问同类 private `render_*`；`dllmain.cpp` 构造函数的 tab 回调简化为调用 `render_main_window`；各 `*_ui.cpp` 内部用 `section_header`/`scoped_accent_button`/宽度对齐做表现细化，函数签名不变。

**Tech Stack:** C++23、ImGui 1.92.1（`BeginTabBar`/`BeginTabItem`/`ImGuiStyle` 全可用）、CMake/Ninja、现有测试目标。

## Global Constraints

- **不改任何运行时行为**：不碰反射路径、UFunction 调用、Hook、跨线程请求交接、安全停用域；纯 ImGui 表现层。
- **`render_*` 函数签名不变**：`PalworldEditorMod::render_give_items/render_item_browser/render_inventory/render_passive_skills/render_active_skills/render_pal_editor/render_base_resource_sharing/render_grapple_no_cooldown/render_pal_identity/render_pal_stats` 的参数与返回类型保持原样。
- **不升版本号**（保持 1.6.10）。
- **不动字体**。
- **不引入第三方 imgui 皮肤库**，只用 imgui 自带 API。
- **构建环境**：所有构建命令须在 VS x64 开发者环境中运行。非开发 shell 须先 `source`/调用 vcvarsall（或用 `scripts/build.ps1`，它会在缺 `cl.exe` 时报错提示）。推荐在 PowerShell 里：

```cpp
/**
 * @file editor_ui.hpp
 * @brief PalworldEditor 界面的共用样式与渲染辅助（纯 ImGui，不依赖 mod 状态）。
 */
#pragma once

namespace editor_ui {
/** @brief 应用深色现代主题到当前进程的 ImGui 全局样式（幂等，每帧调用）。 */
auto apply_editor_style() -> void;

/** @brief 渲染一个小标题 + 全宽分隔线，用作功能块边界。 */
auto section_header(const char* title) -> void;

/**
 * @brief RAII：在其作用域内把按钮临时切换为强调蓝（主操作）。
 * @details 构造时 PushStyleColor 三次，析构时 PopStyleColor(3)。默认按钮色保持中性灰。
 */
class scoped_accent_button {
public:
    scoped_accent_button();
    ~scoped_accent_button();
    scoped_accent_button(const scoped_accent_button&) = delete;
    auto operator=(const scoped_accent_button&) -> scoped_accent_button& = delete;
};
}  // namespace editor_ui
```

```cpp
/** @brief 把 0xRRGGBB 转成 alpha=1 的 ImVec4。 */
ImVec4 rgb(const unsigned hex) {
    return ImVec4{static_cast<float>((hex >> 16) & 0xFF) / 255.0F,

auto section_header(const char* title) -> void {
    ImGui::TextUnformatted(title);
    ImGui::Separator();
}

scoped_accent_button::scoped_accent_button() {
    ImGui::PushStyleColor(ImGuiCol_Button, rgb(0x3a7afe));
    ImGui::PushStyleColor(ImGuiCol_ButtonHovered, rgb(0x5a8fff));
    ImGui::PushStyleColor(ImGuiCol_ButtonActive, rgb(0x2e6ae0));
}

scoped_accent_button::~scoped_accent_button() {
    ImGui::PopStyleColor(3);
}
}  // namespace editor_ui

void PalworldEditorMod::render_main_window(PalworldEditorMod* self) {
    editor_ui::apply_editor_style();
    ImGui::SetNextWindowSize(ImVec2(580.0F, 640.0F), ImGuiCond_FirstUseEver);
    if (!ImGui::Begin("PalworldEditor v1.6.10", nullptr)) {
        ImGui::End();
        return;
    }
    if (ImGui::BeginTabBar("##editor_tabs", ImGuiTabBarFlags_None)) {
        if (ImGui::BeginTabItem("物品")) {
            render_give_items(self);
            render_item_browser(self);
            render_inventory(self);
            ImGui::EndTabItem();
        }
        if (ImGui::BeginTabItem("帕鲁")) {
            render_pal_editor(self);
            ImGui::EndTabItem();
        }
        if (ImGui::BeginTabItem("据点")) {
            render_base_resource_sharing(self);
            render_grapple_no_cooldown(self);
            ImGui::EndTabItem();
        }
        if (ImGui::BeginTabItem("诊断")) {
            render_diagnostics(self);
            ImGui::EndTabItem();
        }
        ImGui::EndTabBar();
    }
    ImGui::End();
}

void PalworldEditorMod::render_diagnostics(PalworldEditorMod* self) {
    editor_ui::section_header("诊断");
    if (ImGui::Button("发现对象")) {
        self->want_discover_.store(true);
    }
}
```
